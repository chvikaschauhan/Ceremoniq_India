# Ceremoniq India

Ceremoniq India is a cultural gifting platform that helps people discover thoughtful gifts connected to Indian traditions, occasions, and regional cultures.

## Project structure

- `client/` — React + Vite frontend
- `server/` — Express API

## Prerequisites

- Node.js 18 or newer
- npm

## Install dependencies

From the project root, install the client and server dependencies separately:

```bash
cd client
npm install
```

```bash
cd ../server
npm install
```

## Run locally

In one terminal:

```bash
cd client
npm run dev
```

In another terminal:

```bash
cd server
npm run dev
```

The API health check is available at `http://localhost:5000/api/health`.
